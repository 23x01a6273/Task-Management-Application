# TaskFlow - Task Management Application

TaskFlow is a modern, full-stack task management suite designed for high-velocity teams.

## Tech Stack

- **Frontend**: React, Tailwind CSS, Lucide React, Vite
- **Backend**: Node.js, Express.js, Socket.IO
- **Database**: MongoDB (Mongoose)
- **Auth**: JWT & Bcrypt

## Features

- Secure User Authentication (Login/Register)
- Full Task CRUD (Create, Read, Update, Delete)
- Real-time Notifications via Socket.IO
- Task Statistics Dashboard
- Advanced Filtering, Searching, and Pagination
- Dark/Light Mode Support
- Responsive Design (Mobile Friendly)

## Getting Started

### Prerequisites

- Node.js installed
- MongoDB (Local or Atlas)

### Installation

1. Clone the repository:
   ```bash
   git clone <https://github.com/23x01a6273/Task-Management-Application>
   ```

2. Setup Backend:
   ```bash
   cd backend
   npm install
   # Create a .env file based on the provided instructions
   npm run dev
   ```

3. Setup Frontend:
   ```bash
   cd ../frontend
   npm install
   npm run dev
   ```
